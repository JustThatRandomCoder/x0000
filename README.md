# x0000

A minimalist portfolio showcase domain for random projects and experiments.

## About

**x0000** serves as a central hub for showcasing various creative projects and experiments. Built with a clean, typographic design philosophy, it features a dark aesthetic with precision-crafted typography using Source Code Pro.

### Features

- 🎨 **Minimalist Design** - Clean, dark interface with focus on typography
- 📱 **Fully Responsive** - Optimized for all device sizes
- ⚡ **Built with Astro** - Fast, modern static site generation
- 🎯 **Project Showcase** - Dynamic project listings and links
- 🔧 **Utility-First CSS** - Custom margin, typography, and layout utilities

## Demo

🌐 **Live Site**: [x0000.de](https://x0000.de)

## Design System

- **Typography**: Source Code Pro (Google Fonts)
- **Color Palette**:
  - Background: `#000000`
  - Text: `#ffffff`
  - Accent: `#A6A6A6`
- **Responsive Breakpoints**: Mobile-first approach with 5 breakpoints
- **Font Sizes**: Scaled from Figma designs (200px, 60px, 30px base sizes)

## Tech Stack

- [Astro](https://astro.build/) - Static Site Generator
- CSS3 - Custom utility classes and responsive design
- TypeScript - Type-safe development
